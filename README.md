# Viettel Telecom — Cửa hàng trực tiếp Lê Văn Lương

Landing page giới thiệu địa điểm cửa hàng **Viettel Telecom - Cửa hàng trực tiếp Lê Văn Lương Thanh Xuân HNI**.

- **Địa chỉ:** Tầng 1 tòa nhà Star City, số 23 đường Lê Văn Lương, phường Thanh Xuân, Hà Nội
- **Điện thoại:** 024 6675 9666
- **Giờ mở cửa:** 08:00 – 20:00, cả tuần (T2 – CN)

## Cách xem / chỉnh sửa

Đây là trang tĩnh **1 file tự chứa** (`index.html`, CSS/JS inline, font Google + bản đồ Google Maps nhúng).
Chỉ cần mở `index.html` bằng trình duyệt là chạy, không cần cài đặt.

```
index.html          # toàn bộ trang
assets/             # ảnh cửa hàng, ảnh sản phẩm, banner
assets/tammi/       # bộ nhân vật Tammi (nhiều pose, nền trong suốt)
```

## Các phần chính

Hero (gallery ảnh + thành tích Top 10) · Khuyến mãi tại quầy (banner) · Trước khi tới ·
Dịch vụ tại quầy · Sản phẩm · Ưu đãi · Đặt lịch hẹn · Cửa hàng gần đây (bản đồ) ·
Đánh giá · Câu hỏi thường gặp · Trợ lý Tammi.

> Nội dung khuyến mãi/sản phẩm/đánh giá hiện là dữ liệu mẫu, có thể chỉnh sửa trực tiếp trong `index.html`.
